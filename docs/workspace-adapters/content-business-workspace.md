# Content Business Workspace Adapter

## Purpose

This adapter defines the generic pattern for a content or media business workspace.

It should not name a specific publication, channel, creator, or brand.

## Typical Needs

- topic research
- editorial planning
- draft preparation
- SEO/content review
- publishing preparation
- content calendar management
- signal capture

## Typical Agents

| Agent | Role |
|---|---|
| Topic Research Agent | Identifies useful topics and themes |
| Editorial Planning Agent | Organizes drafts and schedules |
| Drafting Agent | Produces draft content artifacts |
| QA Agent | Reviews quality, structure, and policy concerns |
| Publishing Prep Agent | Prepares approved content for release |
| Signal Capture Agent | Sends generalized insights to the Observatory |

## Generic Workflow

```text
Human proposes topic or strategy
-> Workspace researches topic context
-> Editorial plan is prepared
-> Draft content is created
-> QA review occurs
-> Human approves publication
-> Content is manually published or scheduled through approved workflows
-> Generalized signals return to the Observatory
```

## Review Gates

- quality gate
- publish gate
- rights and compliance gate
- paid action gate

## Rule

```text
Content workspace agents may draft and organize.
They may not publish public content or spend money without human approval.
```
